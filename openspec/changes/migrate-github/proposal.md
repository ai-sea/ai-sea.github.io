# Proposal

## Why
Enable the owner to edit blog posts in GitHub and publish to the approved public organization homepage.

## What Changes
- Extract seven posts into Markdown files.
- Preserve the homepage and generate independent article pages.
- Automate GitHub Pages publication.

## Capabilities
### New Capabilities
- markdown-blog: editable articles and automatic publication.
### Modified Capabilities
None.

## Impact
New public repository and Pages site. Existing Sites deployment retained.
